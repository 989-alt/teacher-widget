# 교실 위젯

초등 담임 교사를 위한 윈도우 바탕화면 위젯입니다. 바탕화면이 업무 보드가 됩니다.

- 메신저 쪽지에서 일정을 찾아 확인 카드로 알려 주고 캘린더에 넣습니다.
- 캘린더, 다가오는 일정, D-day, 바로가기, 시간표, 급식(나이스), 알레르기 알림
- 날씨·미세먼지, 시계, 메모, 뉴스, 환율·증시 위젯을 골라 넣을 수 있습니다.
- TV에 화면을 복제하거나 발표를 시작하면 일정·메모·학생 정보가 든 칸은 자동으로 가려집니다.

## 설치

1. [설치 파일 받기](https://989-alt.github.io/teacher-widget/teacher-widget-setup-1.0.0.exe)를 눌러 내려받아 실행합니다. (학교 인터넷에서도 열리는 주소입니다. [Releases](../../releases/latest)에도 같은 파일이 있습니다.)
2. 윈도우가 "알 수 없는 게시자" 경고를 띄우면 `추가 정보 → 실행`을 누릅니다. (코드 서명이 없는 프로그램이라 뜨는 경고입니다.)
3. 관리자 권한 없이 사용자 폴더에 설치되고, 끝나면 바로 켜집니다.

윈도우 10·11에서 동작합니다.

## 업데이트

새 판이 나오면 프로그램이 추가·개선 내용과 함께 알려 드립니다. `지금 업데이트`를 누르면 내려받아 설치하고 다시 켜집니다. 설정과 일정은 그대로 남습니다.

## 자료는 어디에 남나요

일정, 메모, 학생 알레르기, 설정은 모두 이 PC의 `%LOCALAPPDATA%\교실위젯`에만 저장됩니다. 쪽지 내용과 학생 정보는 PC 밖으로 나가지 않습니다.

인터넷으로 나가는 것은 다음뿐입니다.

- 급식·학사일정 조회(나이스): 학교 코드와 날짜
- 날씨·미세먼지 조회(Open-Meteo): 시·군·구 좌표
- 환율·뉴스 조회: 직접 넣은 뉴스 검색어
- `협업·연수·개선 요청`을 눌러 직접 보낸 글
- 새 판 확인(이 저장소)

## 문의

수업 도구와 게임은 [교실 놀이터](https://s-edu.ai.kr)에 있습니다. 고칠 점이나 문의는 프로그램 오른쪽 위의 `협업·연수·개선 요청`으로 보내 주세요.
